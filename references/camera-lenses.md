## 4. 摄影术语速查

| 术语 | 含义 |
|------|------|
| 焦距 (mm) | 数值越小视角越广；越大视角越窄 |
| 光圈 (f/) | 数值越小景深越浅；越大景深越深 |
| ISO | 感光度，越高噪点越多 |
| 快门 | 曝光时间 |
| 浅景深 | 背景虚化，主体清晰 |
| 深景深 | 全部清晰 |
| 逆光 | 光源在主体后方 |
| 侧光 | 光源在主体侧面 |

## 5. 国漫专用渲染参数

### UE5 渲染关键词
```
【渲染】UE5 Nanite 超细几何 + Lumen 全局光照
【材质】PBR 材质，皮肤毛孔清晰，发丝根根分明
【光影】电影级 3D 光影，体积光，粒子特效
```

### 后期调色
- **冷白调（仙侠）**：高光偏蓝、阴影偏紫、肤色保留
- **暖黄调（玄幻）**：高光偏黄、阴影偏红、浓郁饱和
- **暗调（魔道）**：整体压暗、对比度提升、饱和度提升
