# 笔触技法手册 / Brush Techniques

> 中国水墨画的 13 种核心笔法，理解它们才能写对提示词。

---

## 1. 笔法总览

| 笔法 | 用途 | 视觉关键词 |
|------|------|-----------|
| 中锋 | 线条主干 | `round brush, central stroke, full-bodied` |
| 侧锋 | 宽面、叶片 | `side brush, broad stroke, varying width` |
| 逆锋 | 飞白、枯笔 | `dry brush, flying white, textural breaks` |
| 拖笔 | 长线条 | `dragging stroke, flowing line` |
| 皴法 | 山石纹理 | `texture stroke, cun technique, layered strokes` |
| 点苔 | 装饰点缀 | `dotting, moss dots, scattered accents` |
| 渲染 | 渐变晕染 | `wet wash, gradient blending, soft edges` |
| 破墨 | 墨色叠加 | `broken ink, overlapping washes, tonal complexity` |
| 泼墨 | 大面积泼洒 | `splash ink, bold wash, dramatic pour` |
| 积墨 | 多层积累 | `layered ink, depth buildup, accumulation` |
| 飞白 | 枯笔飞白 | `flying white, dry texture, brush skip` |
| 留白 | 空白构图 | `negative space, paper preserved, breathing room` |
| 提按 | 笔压变化 | `pressure variation, thick-thin alternation` |

## 5. 特殊笔法效果

### 泼墨（Bold Ink Splash）

适用于：抽象山水、强烈视觉冲击
```
splash ink technique, bold wet washes,
dramatic ink pour, gestural strokes,
expressionistic brushwork
```

### 破墨（Broken Ink）

适用于：丰富层次、云雾、雨景
```
broken ink technique, overlapping washes,
tonal complexity, wet-on-wet blending
```

### 积墨（Layered Ink）

适用于：深邃山水、传统山水
```
layered ink technique, depth buildup,
multiple wash passes, accumulated darkness
```

### 飞白（Flying White）

适用于：枯树、岩石、风雪
```
flying white technique, dry brush skip,
textural breaks, visible paper through strokes
```

## 7. 避免的笔法错误

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| 均匀笔触（数字感）| 笔触粗细变化 |
| 锐利边缘 | 自然晕染 |
| 高饱和度色彩 | 低饱和度墨色 |
| 全图着墨 | 大面积留白 |
| 完美对称 | 自然不对称 |
| 平滑过渡 | 笔触飞白 |

## 8. 工具流派速查

**写意派**（齐白石、徐悲鸿）
- 笔触奔放、造型简练
- 提示词：`freehand brushwork, gestural strokes, expressive`

**工笔派**（宋画院、张大千）
- 笔触工整、细节繁复
- 提示词：`meticulous brushwork, fine detail, gongbi style`

**泼墨派**（张大千、刘海粟）
- 大面积泼墨、抽象意境
- 提示词：`splash ink, bold wash, abstract expression`

**没骨派**（恽寿平）
- 不勾轮廓、直接用色
- 提示词：`boneless technique, direct color, no outlines`
