## 1. 整体美术风格

| 维度 | 定义 |
|------|------|
| 技术形态 | 手绘水墨、宣纸毛笔、传统国画技法 |
| 渲染质感 | 笔触可见、墨色浓淡、晕染自然 |
| 写实/写意比例 | 约 2:8 — 写意为核心，形似次之 |
| 视觉关键词 | 留白、意境、诗意、空灵、禅意 |

**对比参考**：
- ❌ 数字绘画：均匀、平滑、CG 感
- ❌ 日漫风：线稿+赛璐璐
- ✅ 国风水墨：毛笔+宣纸+墨色变化

## 2. 墨色浓淡（Ink Density）

水墨画的灵魂是**墨分五色**——焦、浓、重、淡、清。

### 五级墨色

| 墨色 | 视觉 | 适用场景 |
|------|------|----------|
| **焦墨** | 最浓、近黑 | 点睛、关键细节（鸟眼、印章） |
| **浓墨** | 浓黑 | 主干、主体轮廓 |
| **重墨** | 深灰 | 主体结构、次要细节 |
| **淡墨** | 浅灰 | 远山、雾、远景 |
| **清墨** | 极浅 | 留白边缘、晕染过渡 |

### 三档预设

**light（淡墨）** —— 用于诗意留白、极简构图
```
light ink wash, mostly empty paper, hint of brush,
high negative space ratio, ethereal, Zen
```

**medium（中墨）** —— 最常用的标准档
```
medium ink density, balanced coverage,
clear subject with atmospheric depth,
traditional shuimo painting
```

**bold（浓墨）** —— 用于强烈视觉冲击
```
bold ink, strong brush strokes, dramatic composition,
high contrast black ink on white paper,
expressionistic, powerful
```

## 3. 笔触技法（Brush Techniques）

### 必备笔触关键词

| 笔法 | 视觉 | 提示词 |
|------|------|--------|
| 中锋 | 圆润、饱满 | `round brush strokes, full-bodied strokes` |
| 侧锋 | 宽窄变化 | `side brush strokes, varying width` |
| 逆锋 | 飞白、枯笔 | `dry brush, flying white, textural breaks` |
| 拖笔 | 长线条 | `dragging strokes, flowing lines` |
| 点苔 | 散点装饰 | `dotting accents, scattered ink dots` |
| 皴法 | 山石纹理 | `texture strokes for rocks, cun technique` |
| 渲染 | 渐变晕染 | `wet wash, gradient blending, ink wash splashing` |

### 提示词集成示例

```
hand-painted brushwork, visible brush strokes,
dry-brush breaks in texture, wet blooms in wash areas,
flying white edges on mountainside, dotting moss accents,
rice paper texture underneath
```

## 4. 色彩体系

### 传统三档

**monochrome（纯水墨）** —— 最经典
```
pure black ink on white/cream rice paper,
monochrome, no color, traditional shuimo
```

**accent-red（朱砂点缀）** —— 国画经典配色
```
monochrome with subtle red accents,
vermillion plum blossoms, red seal stamp,
red ribbon on hair, red lip detail
```

**accent-gold（金色点缀）** —— 皇家/神圣题材
```
monochrome with subtle gold accents,
golden dragon, gold seal stamps,
gold thread embroidery, gilded edges
```

### 用色禁忌

| ❌ 不要 | ✅ 应该 |
|---------|---------|
| 高饱和度（红、黄、蓝、绿）| 低饱和度（赭石、花青、藤黄）|
| 多色并用 | 单色为主，少量点缀 |
| 均匀配色 | 墨色浓淡变化 |
| 数字色彩 | 传统国画颜料 |

## 5. 构图法则

### 三远法（郭熙《林泉高致》）
- **高远** —— 仰视，山势险峻（山水诗）
- **深远** —— 自前山看后山，层次深远
- **平远** —— 自近山看远山，冲淡平和（最常用）

### 留白原则
- **计白当黑**：空白处也是构图的一部分
- **虚实相生**：实（主体）+ 虚（背景）平衡
- **疏密有致**：不能处处着墨，要有疏密变化

### 经典构图
- **边角构图**：主体在画面一角，大面积留白（南宋马远）
- **S 形构图**：河流、山脉呈 S 形蜿蜒
- **对角线构图**：从一角到另一角
- **三角形构图**：山势稳定

## 6. 空间处理

### 五层空间

| 层 | 视觉处理 | 提示词 |
|----|----------|--------|
| 近景 | 浓墨、清晰 | `foreground with bold ink, sharp detail` |
| 中景 | 重墨、主体 | `middle ground, main subject, medium ink` |
| 远景 | 淡墨、虚化 | `distant mountains, light wash, atmospheric` |
| 天际 | 清墨、朦胧 | `sky boundary, lightest ink, soft edges` |
| 留白 | 几乎无墨 | `vast empty paper, pure negative space` |

## 7. 常见错误避免

| 错误 | 表现 | 解决方案 |
|------|------|----------|
| 数字感 | 太干净、太均匀 | 加 `visible brush strokes, paper texture` |
| 色彩杂 | 用了鲜艳色 | 加 `monochrome, no color, traditional` |
| 比例失 | 太空或太满 | 加 `balanced composition, restrained detail` |
| 混日漫 | 线稿+赛璐璐 | 加 `no line art, no cel-shading, painterly` |
| 3D 化 | 立体感过强 | 加 `2D flat, no 3D, hand-painted` |
| 现代元素 | 出现汽车 | 加 `no modern elements` |

## 8. 与其他风格的区分

### vs 国漫 3D
- 国漫 3D：立体、写实、电影感、UE5 渲染
- 国风水墨：平面、写意、诗意、毛笔宣纸

### vs 日漫
- 日漫：线稿、赛璐璐、二次元眼睛
- 国风水墨：墨色、晕染、写意留白

### vs 数字插画
- 数字插画：均匀、CG 感、商业化
- 国风水墨：笔触、传统、文艺气息
