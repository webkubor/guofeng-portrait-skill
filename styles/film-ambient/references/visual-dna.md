# 视觉基因 / Visual DNA — 古风氛围胶片人像 (film-ambient)

> **核心问题**：什么让一张图看起来像「用胶片拍的一段东方影像」，而不是「影楼汉服写真」？
>
> 答案不在形制考究，在**氛围与情绪的浓度**。这套画法卖的不是"漂亮的汉服妹"，
> 是**一段有情绪、且正在消逝的东方影像**。

> 📖 **通用审美层先读**：[`AESTHETIC.md`](../../../AESTHETIC.md) —— 六条第一性原理、推导链、
> 诊断回路。本文是它在「真实摄影 / 胶片」这一媒介上的落地。

---

## 1. 一句话定义

**用电影摄影的语言拍古装少女。** 重心在氛围，不在形制。

| 维度 | 定义 |
|------|------|
| 技术形态 | 真实摄影（real photography），非 CG、非渲染、非插画 |
| 画面来源 | 日系胶片扫描质感 + 东方电影摄影 |
| 写实/风格化 | 9:1 — 几乎纯写实，风格化只体现在调色与光 |
| 视觉关键词 | 清透、低饱和、斑驳光影、空气感、易碎感、电影静帧 |
| 情绪基调 | 清冷、静谧、疏离、怅惘 —— 所有意象都是**将逝之物**（雪 / 落花 / 暮色 / 灯火） |

**对比参考**：
- ❌ 影楼汉服写真：正面平光、饱和度高、摆拍、复杂发冠满头珠钗
- ❌ 仙侠玄幻：发光粒子、法阵、荧光特效、CG 光晕
- ❌ 二次元 / 游戏原画：赛璐璐、平涂、二次元眼睛
- ✅ film-ambient：真人抓拍 + 斑驳自然光 + 胶片质感 + 含蓄情绪

> **想直接出图**：21 个命名风格见 [`style-presets.md`](style-presets.md) ——
> 一条 `--preset 花影柔光` 就是本节全部规则的一套具体落地。本文档是"原理"，
> 那份是"菜单"。

## 2. 七维审美指纹（每一条都是硬约束）

| # | 维度 | 必须满足 | 常见错误 |
|---|------|---------|---------|
| ① | **色彩** | 低饱和；主色只有三个：**雾白 / 灰青 / 烛金**，红色只留在唇；**阴影呈灰绿色**（不是死黑）；高光微微泛白 | 高饱和糖果色、鲜艳大红大绿、阴影死黑 |
| ② | **光** | **有来源、有方向的自然光**；侧逆光优先；**发丝轮廓光** + 纱料透光；绝不正面平光 | 棚拍平光、双灯补光、无方向的环境光 |
| ③ | **质感** | 真实摄影：皮肤保留毛孔与微血色；**胶片型号锚点**（`--film`，默认 Pro 400H 青绿通透）；柔和高光晕染；浅景深奶油散景；画面"不锐利" | 过度磨皮、塑料皮肤、强 HDR、过度锐化 |
| ④ | **构图** | **前景遮挡**（花枝 / 竹叶 / 雪 / 落瓣 / 灯笼 / 剑）形成前后景层次；大量留白；人物偏置不占满；半身/近景为主 | 证件照式居中、人物顶满画面、无层次 |
| ⑤ | **造型** | 乌黑长发**半披半束**，发型简洁；发饰**极少**（一根细窄浅色丝带 / 一支素簪 / 一朵花）；素色轻薄纱衣，无繁复刺绣 | 复杂发冠、满头珠钗、厚重头饰、华丽刺绣 |
| ⑥ | **情绪** ⭐ | 姿态**静态内敛**：倚 / 趴 / 蹲坐 / 回眸 / 仰望 / 垂眸；神情清冷、疏离、易碎；**不露齿笑** | 大笑、强动作、刻意摆拍、直视镜头的营业笑 |
| ⑦ | **抓拍感** ⭐ | **像摄影师突然叫住她的一瞬间** —— 身体自然放松、动作停在半途、眼神是"被抓拍到的"而不是"在演" | 端着姿势等拍、表演感、僵硬对称 |

> ⭐ ⑥⑦ 是本画法的分水岭。少了这两条，前面的色彩和光影做得再对，
> 出来的也是"精致的摆拍"，不是"你的审美"。

## 3. 色彩体系

### 主色调（只用这三个 + 黑发）

| 颜色 | 用途 | 经典场景 |
|------|------|----------|
| **雾白 / 月白** | 主服色、留白、雪、纱料 | 素衣少女、雪庭、湖畔 |
| **灰青 / 青绿** | 环境色、次服色、竹、水、阴影 | 竹林、庭院植物、青石 |
| **烛金 / 暖橙** | 唯一暖色，只出现在光源处 | 灯笼、油灯、夕阳、暮色 |
| **墨黑** | 长发、暗部结构 | 全部画面 |

### 饱和度与明度策略

- **整体饱和度**：低（比 3d-realistic 低 2-3 档），接近莫兰迪
- **高光**：微微泛白（slightly blown highlights），不是纯白死白
- **阴影**：呈**灰绿色**（grey-green shadows），抬起而非压死
- **肤色**：自然暖白，与环境形成柔和对比，不发灰不发黄
- **红色**：几乎只出现在唇色，绝不进入服饰大面积

### 胶片型号锚点（`--film`）⭐

**模型对具体胶片名的响应，远强于"胶片质感 / film grain"这类泛词** ——
一个型号名同时锁定了色彩倾向、宽容度、高光行为与颗粒粗细。这是把"胶片感"
从形容词变成硬锚点的手段。

| 型号 | `--film` | 色彩倾向 | 配什么场景 |
|------|----------|---------|-----------|
| **Fujifilm Pro 400H** ⭐ 默认 | `pro400h` | **青绿偏冷**、通透薄荷调、高光柔和溢出、肤色干净不发黄 | 本画法的招牌 —— 竹林、绿意、雪庭、庭院（**九宫格的主色调就是它**） |
| **Kodak Portra 400** | `portra400` | **暖调奶油肤**、宽容度高、阴影柔和通透 | 灯下夜读、暮色、室内暖光 |
| **Fujifilm Superia** | `superia` | 轻微偏青、颗粒明显、**生活化的不精致** | 日常纪实、街拍感、"被随手拍到" |
| **CineStill 800T** | `cinestill800t` | 钨丝灯夜景：**暖色光晕 halation**、暗部深蓝、颗粒粗 | 提灯夜行、夜色庭院、灯火 |
| 通用 | `none` | 只说"日系胶片扫描质感"，色彩交给固定层 | 不确定时的保底 |

**选型逻辑**：
- 要**青绿通透**（本画法招牌) → `pro400h`
- 要**暖调温柔**（灯 / 暮色）→ `portra400`
- 要**真实粗糙**（纪实感）→ `superia`
- 要**夜戏电影感** → `cinestill800t` + `--light lantern-night` 或 `lamp-warm`

> ⚠️ 一次只用一个型号。混两个（"Portra 的青绿"）会让模型两头不靠。

## 4. 光型库

7 种经过验证的光型见 `light-patterns.md`。核心原则：

1. **逆光 / 侧逆光优先** —— 9 张标杆图里 7 张是逆光
2. **光必须有来源**：树叶、雪、灯笼、夕阳、窗户 —— 说不出光源的光不要
3. **发丝轮廓光是签名** —— 每张图都要有
4. **永不用正面平光** —— 那是最像"影楼"的一件事

## 5. 造型清单
**发型**：长黑发，半披半束 / 松挽低髻 / 仅一根丝带固定
**发饰**：一根细窄浅色丝带 / 一支素簪 / 一朵花 —— 上限就是一件
**服饰**：素色交领 / 对襟褙子 / 宽袖纱衣；雾白、月白、浅青、青绿、墨黑
**面料**：轻薄、透光、有细腻丝织纹理，能被风吹动
**缺席的**：复杂盘发、发冠、步摇、珠钗、刺绣大袖、华丽纹样

## 6. 与另外两套画法的边界

| | `3d-realistic` | `ink-wash` | **`film-ambient`** |
|---|---|---|---|
| 本质 | 3D 渲染 | 手绘水墨 | **真实摄影** |
| 光 | 体积光、仙侠光效 | 无光（墨色浓淡） | **自然光、侧逆光** |
| 色彩 | 中高饱和 + 光效强调色 | 黑白 + 朱砂/金 | **低饱和三色** |
| 皮肤 | 毛孔发丝可见（渲染） | 不适用 | **保留真实肌理（实拍）** |
| 情绪 | 气势、玄幻 | 空灵、禅意 | **清冷、易碎、抓拍** |

**三者提示词不可混用**：把「仙侠光效」写进 film-ambient 会立刻变成廉价玄幻；
把「胶片颗粒」写进 ink-wash 会毁掉水墨。各套 references 独立。
