## 模型详解

### 🥇 Seedream（火山方舟）—— **国漫首选**

**优势**：
- 东方审美调校最佳，国漫脸型最正
- 中文提示词理解深度最强
- 仙侠玄幻题材表现稳定
- 价格适中（¥0.2-0.3/张）

**劣势**：
- 写实度略低于 GPT-image-2
- 复杂构图偶尔翻车

**推荐用法**：
```
museav gen --prompt "<中文提示词>" --model Seedream --quality high
```

**调优技巧**：
- 加 `写实人像` 提高写实度
- 加 `中国3D动漫风格` 强化风格
- 比例 3:4 时表现最佳

---

### 🥈 gpt-image-2 —— **光影氛围之王**

**优势**：
- 光影氛围、情绪表达最佳
- 皮肤质感、毛孔细节优秀
- 适合写实仙侠人像
- Medium 质量档性价比高

**劣势**：
- High 档成本高（¥1.5/张）
- 中文理解略弱于国产模型
- 需要用英文提示词更稳

**推荐用法**：
```
museav gen --prompt "<英文提示词>" --model gpt-image-2 --quality medium
```

**调优技巧**：
- 用英文提示词效果更稳定
- 强调 `cinematic lighting` 提升氛围
- Medium 档足够日常使用

---

### 🥉 qwen-image-3.0 —— **性价比之王**

**优势**：
- 价格最低（¥0.18/张）
- 中文理解稳定
- 适合批量出图试方向
- 国风质感不错

**劣势**：
- 细节略逊于 Seedream / GPT
- 复杂场景把握一般

**推荐用法**：
```
museav gen --prompt "<中文提示词>" --model qwen-image-3.0
```

**调优技巧**：
- 适合试稿阶段，4 张选 1
- 跑出方向后再用精模精修
- 简洁提示词效果更稳

---

### 🎨 Midjourney v6 —— **创意来源**

**优势**：
- 创意发散、艺术感强
- 适合找灵感、做概念
- 风格化处理能力强

**劣势**：
- 中文理解弱（建议用英文）
- 订阅制成本不透明
- 国漫 3D 还原度一般

**推荐用法**：
```
museav gen --prompt "<英文提示词>" --model midjourney --quality high
```

**调优技巧**：
- 加 `style raw` 减少 MJ 风格化
- 加 `--s 50` 降低风格化强度
- 适合前期灵感探索

## 出图工作流（推荐）

```
阶段 1：灵感探索
├─ qwen-image-3.0 × 4 张（试方向）
└─ 选出最佳构图 / 角色

阶段 2：精修
├─ Seedream 或 gpt-image-2 × 2 张
└─ 中等质量档

阶段 3：终稿
└─ Seedream / gpt-image-2 × 1 张
   └─ 高质量档
```

## 通用建议

1. **批次策略**：每张图成本不同，建议先用低成本模型试方向
2. **提示词版本**：同一提示词在不同模型上需要微调
3. **质量档位**：Medium 已足够日常使用，High 留给终稿
4. **比例固定**：3:4 / 16:9 / 9:16 / 1:1 四大标准
5. **样图参考**：先用 seedream 出样图，再用 gpt-image 精修
