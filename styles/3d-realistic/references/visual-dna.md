# 视觉基因 / Visual DNA

> **核心问题**：什么让一张图看起来「像斗罗大陆 / 斗破苍穹 / 灵笼」而不是「像日漫 / 像好莱坞 3D」？

---

## 1. 整体美术风格

| 维度 | 定义 |
|------|------|
| 技术形态 | UE5 Nanite + Lumen 全局光照、PBR 材质、次世代角色渲染 |
| 渲染质感 | 电影级 3D 光影，体积光，粒子特效，动态模糊 |
| 写实/卡通比例 | 约 5:5 — 写实人物比例 + 风格化服装/光效 |
| 视觉关键词 | 仙气、玄幻、东方美学、气势磅礴、电影感 |

**对比参考**：
- ❌ 日漫风：平面、赛璐璐、二次元眼睛
- ❌ 好莱坞 3D：写实肌肉、西方盔甲、好莱坞色调
- ✅ 国漫 3D：东方审美 + 写实渲染 + 仙侠光效

## 2. 色彩体系

### 主色调
| 颜色 | 用途 | 经典场景 |
|------|------|----------|
| 冰蓝 / 霜蓝 | 冰系剑气、寒冰体质 | 冰属性剑修 |
| 深红 / 朱砂 | 火系法术、血脉觉醒 | 萧炎、魔尊重生 |
| 翠绿 / 墨绿 | 木系、毒系、生命 | 唐门暗器 |
| 玄金 / 鎏金 | 宗门圣物、高阶法宝 | 斗宗 / 斗尊境界 |
| 水墨黑 | 主色调、阴影、深度 | 玄幻写实通用 |
| 留白雾色 | 仙气、云海、留白 | 仙门山门 |

### 饱和度策略
- **角色主色**：中-高饱和，突出角色
- **环境辅色**：低饱和（远景几乎去饱和）
- **光效强调色**：高饱和（金光 / 蓝光 / 紫光）
- **整体基调**：电影调色，非动漫"糖果色"

## 3. 角色设计原则

### 身材比例
- 男角色：约 7-7.5 头身（接近写实）
- 女角色：约 6.5-7 头身（修长但不夸张）
- 儿童角色：约 5-6 头身（保留可爱感）

### 五官特征
- 眼睛：大而有神，眼中有光（"星辰倒影"），眼线清晰
- 眉毛：剑眉、浓眉、飘逸眉（与性格匹配）
- 鼻梁：高挺，立体感强
- 下颌：棱角分明（男）/ 柔和流畅（女）
- 肤质：毛孔可见、肤色调统一，避免"塑料感"

### 发型设计
- 必备要求：「发丝根根分明、有光泽变化」
- 男角色常见：高束马尾、长发披肩、半束发髻
- 女角色常见：飞仙髻、双环髻、披散长发 + 额饰
- 颜色：黑色为主，其次白色（高阶）、红色（魔化）、蓝色（冰系）

### 服饰规范
- **男性**：劲装（战斗用）、长袍（宗门）、战甲（将军）
- **女性**：襦裙（古装）、仙裙（飘逸）、战裙（战斗）
- **材质**：丝绸（柔）、皮革（粗）、金属（甲）、纱（透）
- **纹样**：云纹、龙纹、凤纹、花卉、几何纹

## 4. 光影处理

### 三点布光原则
1. **主光（Key Light）**：侧逆光，勾勒轮廓
2. **辅光（Fill Light）**：环境光，填充阴影
3. **轮廓光（Rim Light）**：背光 / 侧逆光，区分背景

### 国漫特色光效
- **体积光**：阳光穿透云层 / 森林的光柱
- **发光体**：剑气、灵气、法阵
- **粒子**：飞散的樱花、飘落的雪、灵力火星
- **光晕**：高阶法师身上的金色 / 紫色光环
- **光剑 / 光痕**：武器划过空气留下的光迹

### 镜头光晕
- 适度使用镜头光晕（Lens Flare）
- 避免过度炫光，保持电影感

## 5. 人像的环境与构图

> 这是**人像 skill**，环境只服务于人物——背景怎么虚、怎么让人物立住，
> 而不是把场景本身当主体来画。

### 空间纵深
- **前景**：散落道具（落花、落叶、碎片）
- **中景**：主体人物
- **远景**：虚化的山、云、雾
- **天际**：光源 / 天空 / 飞鸟

### 构图原则
- **三角形构图**：角色 + 前景物 + 远景
- **对角线构图**：战斗场面
- **中心构图**：海报主视觉
- **留白构图**：仙侠意境

## 6. 渲染规格

### 必备关键词
- `UE5` / `Unreal Engine 5`
- `Nanite` / `Lumen`（几何 / 光照）
- `PBR materials`（材质）
- `cinematic 3D lighting`（光影）
- `next-gen character render`（角色）
- `volumetric light` / `god rays`（体积光）
- `particle effects`（粒子）
- `motion blur`（动态模糊）

### 质量档位
| 档位 | 关键词 | 适用 |
|------|--------|------|
| 高质量 | `masterpiece, ultra detailed, 8K, cinematic` | 终稿 |
| 中等 | `high quality, detailed, 4K` | 日常 |
| 草稿 | `good quality, decent detail` | 试方向 |

## 7. 常见错误避免

| 错误 | 表现 | 解决方案 |
|------|------|----------|
| 塑料感 | 皮肤像塑料 | 加 `skin pores visible, natural skin texture` |
| 头发糊 | 像一团黑 | 加 `individual hair strands, hair shine` |
| 手部畸形 | 6 根手指 | 加 `anatomically correct hands, five fingers` |
| 武器比例错 | 剑太长/太短 | 加 `proportionally correct sword` |
| 中西混杂 | 西式盔甲 + 中式发型 | 强调 `historically consistent Chinese hanfu` |
| 现代元素 | 突然出现汽车 | 加 `no modern elements` |

## 8. 与其他风格的区分

### vs 日漫 2D
- 日漫：平面、赛璐璐、大眼卡通
- 国漫 3D：立体、写实、电影感

### vs 好莱坞 3D
- 好莱坞：写实肌肉、西方审美、动作捕捉感
- 国漫 3D：东方审美、仙侠飘逸、灵气粒子

### vs 古风 2D
- 古风 2D：工笔 / 写意 / 水墨
- 国漫 3D：3D 渲染、写实质感、电影构图
