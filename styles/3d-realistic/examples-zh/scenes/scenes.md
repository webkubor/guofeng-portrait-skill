# 场景示例

## 仙门山门

```
国产 3D 动漫风格，仙侠宗门山门全景，
巨大石质山门矗立云海之上，门上刻有「天剑宗」三字，
石阶蜿蜒而上，两侧有石灯和古松，
云海翻涌，远处有仙鹤翱翔，瀑布从山巅倾泻，
黄昏时分，金色阳光穿透云层，形成丁达尔效应，
【镜头】24mm 广角，深景深，全景构图
【渲染】UE5，大气散射，体积云，远景雾气
【风格】仙侠宗门，东方美学，气势恢宏
比例 16:9
```

## 修炼洞府

```
国产 3D 动漫风格，修士修炼洞府内景，
中央有蒲团和矮案，案上有古籍和丹炉，
洞壁有天然钟乳石，滴水形成小潭，
墙上刻有古朴修炼法阵，泛着微弱蓝光，
顶部有天窗，月光倾泻而下，照亮漂浮的灵气粒子，
【镜头】35mm，f4.0，环境光
【渲染】UE5，动态体积光，水面反射，材质细节
【风格】神秘洞府，修炼氛围，东方仙韵
比例 16:9
```

```

## 天界神域

```
