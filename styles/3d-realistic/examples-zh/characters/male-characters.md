# 剑修特写示例

## 清冷剑修（特写）

```
国产 3D 动漫风格，一位青年剑修的面部特写，眉宇冷峻，眼神锐利看向画外，
黑色长发高束，鬓角有几缕碎发，脸部轮廓棱角分明，
身穿深色劲装，肩甲有银色金属纹路，
侧逆光打在发丝上形成金色轮廓光，
背景虚化的月下山巅，薄雾弥漫，
【镜头】85mm f1.4，浅景深，Sony A7R V
【渲染】UE5 Nanite + Lumen，皮肤毛孔清晰，发丝根根分明
【风格】仙侠玄幻，国产 3D 动漫，电影级光影
比例 3:4
```

## 霸气宗主（半身）

```
国产 3D 动漫风格，中年男子半身像，气质威严，目光深邃，
白色长发披肩，剑眉星目，下巴有短须，面部有岁月痕迹但不显老态，
身穿玄色宗主长袍，金色刺绣云纹，腰间玉佩，
右手轻抚长剑剑柄，左手负于身后，
场景：宗门大殿，烛光摇曳，巨柱撑天，
【镜头】50mm f2.0，伦勃朗光
【渲染】次世代角色渲染，衣物物理模拟，金属材质光泽
【风格】东方美学，气势磅礴，仙侠玄幻
比例 3:4
```

## 魔尊（全身）

```
国产 3D 动漫风格，黑袍男子全身像，正在释放魔气，
血红色长发狂舞，瞳孔变为血红色，面容邪魅，
身穿黑色魔纹长袍，袍角被魔气托起悬浮，
双手张开，周围环绕黑色魔气和红色闪电，
脚下是崩裂的大地，远处有毁灭的城市废墟，
【镜头】24mm 广角，仰视构图，f4.0
【渲染】UE5 Lumen，体积雾，粒子系统，环境破坏
【风格】暗黑玄幻，毁灭美学，史诗感
比例 3:4
```
