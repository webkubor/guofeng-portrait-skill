# 女性角色示例

## 清冷仙子（特写）

```
国产 3D 动漫风格，少女面部特写，肤若凝脂，眉眼如画，
眼神清冷疏离，嘴角微抿，黑色长发如瀑垂落，
发间点缀银色流苏簪，耳畔有碎发随风轻扬，
身穿淡蓝色仙裙，领口有精致云纹刺绣，
侧逆光打在发丝上，形成通透的蓝色轮廓光，
背景虚化的云海翻涌，远处有仙山若隐若现，
【镜头】85mm f1.8，浅景深，Canon EOS R5
【渲染】UE5，皮肤有呼吸感，发丝半透明通透，眼中有星辰倒影
【风格】仙侠玄幻，东方美学，清冷出尘
比例 3:4
```

```

比例 3:4
```
