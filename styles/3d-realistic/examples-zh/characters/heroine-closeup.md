## 第一条：核心比例

> **70% 真人质感 + 30% 国漫理想化**

这一句是整个画法的分水岭。没有它，模型会滑向两个极端：

| 缺少约束 | 结果 |
|---|---|
| 全写实（100% 真人） | 没有国漫味，退化成普通古装摄影 |
| 全动漫（100% 理想化） | 塑料皮、游戏 NPC 脸、二次元平涂 |
| **70/30（正确）** | **美型但保留真人骨相 —— 大眼但不失精致** |

配套的脸型约束同样关键：**精致小鹅蛋脸 + 成年少女骨相**（面中饱满、下颌线流畅、
下巴短小圆润不尖不长）。**不做幼童化娃娃脸** —— 这是旧版最大的失败点：
只写"避免动漫大眼"却不堵幼童脸，模型会默认滑向娃娃脸。

## 第二条：槽位映射

| 槽位 | 取值 |
|------|------|
| `--preset` | `heroine-closeup` |
| `--category` | `character-female` |
| `--framing` | `closeup-head` 超近头肩肖像（脸占 70-80%，正面微微偏侧） |
| `--light` | `warm-backlight` 暖金侧逆光（左后方夕阳 + 金色发丝轮廓光 + 面部柔光不过曝） |
| `--scene` | `dusk-courtyard` 黄昏古代庭院（木质建筑 + 暖黄灯笼光斑，背景完全虚化） |
| `--mood` | `gentle-approach` 轻轻向镜头靠近，直视镜头 |

```bash
python scripts/build_prompt.py --style 3d-realistic \
  --preset heroine-closeup --category character-female \
  --subject "轻轻向镜头靠近，直视镜头" --ratio 3:4
```

## 这张为什么是对的（逐条对照 `AESTHETIC.md`）

| 原理 | 在这张上的体现 |
|---|---|
| **§2.4 情绪浓度 > 造型精度** | "轻轻向镜头靠近，直视镜头" —— 有瞬间、有情绪，不是摆姿势 |
| **§2.3 光必须有出处** | 暖金夕阳从左后方来 + 灯笼光斑；面部柔光不过曝，阴影保留立体骨相 |
| **§2.5 真实感来自不完美** | 微毛孔、真实血色、自然碎发划过脸颊、克制高光 —— 不磨皮不蜡像 |
| **§2.1 克制法则** | 发饰只有白玉花 + 珍珠流苏 + 丝带，**明确写"不堆砌"**；无复杂刺绣 |
| **§2.6 对比度预算** | 低饱和、干净；背景完全虚化，只留灯笼光斑作为氛围信息 |
| **§2.2 暗示优于直给** | 背景虚化 + 微微偏侧，不把信息说尽 |
| **§2.3 反面：旧版病灶** | 明确排除"仙侠荧光 / 满天飞光 / 通用云海背景" |

## 常见失败与归因

| 症状 | 归因 | 处方 |
|---|---|---|
| 娃娃脸 / 幼态 | 缺年龄与骨相约束 | 加"成年少女骨相"；负面补 幼童 / 儿童脸 / 过度婴儿肥 |
| 塑料皮 / 蜡像 | 缺皮肤规格 | 加 SSS + 微毛孔 + 真实血色；负面补 磨皮 / 塑料皮 / 蜡像 |
| 大眼但不精致 | 缺脸型约束 | 加"精致小鹅蛋脸 + 圆润杏眼 + 真实虹膜晶体层次"，不要只写"大眼睛美女" |
| 满头珠翠 | 缺克制约束 | 发饰写死"小巧精致、不堆砌"；负面补 发饰堆砌 / 满头珠翠 |
| 满屏荧光、廉价 | 光无出处 | 换 `--light warm-backlight`（有具体光源）；负面补 仙侠荧光粒子 / 魔法光带 |
| 网红脸 / 韩式脸 | 训练数据偏向 | 负面必须带 网红脸 / 韩式整容脸 / 蛇精脸 |
| 背景杂乱抢戏 | 缺背景约束 | 场景槽位已内置"背景完全虚化"，确认没被 `--subject` 覆盖 |
| 每次脸不一样 | 工程层 | 用 `--ref` 垫图锁脸（见 `references/model-recommendations.md`） |
