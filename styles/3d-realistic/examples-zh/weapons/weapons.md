# 武器法宝示例

## 飞剑/仙剑

```
一柄仙侠飞剑，剑身修长，泛着冰蓝色灵光，
剑格有龙纹雕刻，剑柄缠绕黑色丝带，
剑身周围环绕剑气和冰晶粒子，
悬空漂浮，微微颤动，蓄势待发，
背景虚化，暗色调，突出剑的质感，
【材质】金属 PBR，冰属性发光材质，剑气粒子
【渲染】UE5，材质细节，粒子特效，环境反射
比例 1:1
```

## 魔刀/邪器

```
一柄魔道邪刀，刀身漆黑如墨，有血红色纹路脉动，
刀刃处有黑色魔气缭绕，散发不祥气息，
刀柄是白骨造型，镶嵌红色宝石，
放置在石台上，周围地面龟裂，魔气蔓延，
【材质】黑曜石质感，魔气体积雾，血色发光
【渲染】UE5，暗黑材质，体积雾，粒子特效
比例 1:1
```

## 法宝 - 灵珠

```
一颗仙侠灵珠，珠体通透，内部有星光流转，
珠身周围环绕着柔和的灵光和灵气粒子，
悬浮在半空，微微旋转，散发温暖光芒，
背景虚化，暗色调，突出珠的质感，
【材质】琉璃质感，发光材质，灵气粒子
【渲染】UE5，材质细节，粒子特效，环境光
比例 1:1
```

## 法宝 - 古琴

```
一把仙侠古琴，琴身由千年灵木制成，木纹清晰，
琴弦泛着金色灵光，琴尾有龙凤雕刻，
琴身周围环绕着音波涟漪和灵光粒子，
放置在石案上，案上有香炉和茶盏，
【材质】木材 PBR，金属琴弦，音波粒子
【渲染】UE5，材质细节，粒子特效，环境光
比例 16:9
```
