## 魏晋韵核心 5 元素（基于通用骨架的魏晋专属分支）

### 人物：飘逸出尘 = 超然物外
魏晋审美核心是「逸」，与唐的"盛"、宋的"清"都不同。

- **身形**：清瘦（与唐的丰腴相反）
- **气质**：超然 / 隐逸 / 自由不羁（竹林七贤 / 陶渊明式）
- **神态**：远眺 / 抚琴 / 对月 / 闲步，**不带任何俗世焦虑**
- **发型**：飞天髻 / 灵蛇髻（飘逸）+ 素纱飘带（区别于唐的金翠和宋的素簪）

### 服饰：杂裾垂髾服 + 宽袖
魏晋特有形制，融合汉 + 草原 + 玄学审美：

- **杂裾垂髾服**：下摆裁成三角或燕尾形，走路时飘举（最显著特征）
- **宽袖大袖衫**：袖口宽达 1 尺以上，挥袖可遮面
- **薄纱蝉衣**：单层极薄纱，可隐约见肤（洛神赋"皎若太阳升朝霞"）
- **素色玄青**：玄色（黑带红）/ 天青色 / 素白（区别于唐的艳丽、宋的暖杏）

### 场景：自然山水 + 留白
- **松竹 + 流水 + 月** 是魏晋标配
- 户外：山间 / 溪畔 / 松下 / 月下 / 竹林深处
- 室内：草堂 / 茅舍（隐逸风骨）
- 远景：云山墨色（写意）

### 光影：晨昏 + 月
- **晨昏**：与宋相似（柔光、漫射）但色调更**冷**（玄青而非暖杏）
- **月**：魏晋"对月"场景极常见，月光清冷 + 人物静谧
- 不要艳阳（与宋"傍晚黄金侧逆光"都不同）

### 色彩：玄青 + 天青 + 鹤灰
- **玄色**（深黑偏红）—— 魏晋"玄学"字面颜色
- **天青色**（汝窑蓝）
- **鹤灰**（淡灰）
- **素白**
- **唯一亮色**：偶尔一抹**朱砂红**（唇、衣带扣）作为点睛
