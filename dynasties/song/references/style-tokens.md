## 8. 反面（宋韵里不要的）

| ❌ 关键词 | 原因 |
|---------|------|
| `opulent, luxurious, rich fabric` | 宋韵淡雅，反奢华 |
| `gold jewelry, phoenix crown, ruby` | 宋不戴金翠满头（唐才有） |
| `bold contrast, vibrant, saturated` | 高饱和撞色 = 唐色调 |
| `thick brocade, heavy embroidery` | 宋是薄纱褙子，不是厚重锦缎 |
| `sharp eyeliner, dramatic makeup` | 宋制"清"字诀，妆要淡 |
| `khaki, navy, royal blue` | 这些是明清/明色调，不是宋 |
