## 唐韵核心 5 元素（基于通用骨架的唐专属分支）

### 人物：丰腴雍容 = 自信
唐代审美核心是「盛」，与宋的"淡"相反。

- **身形**：丰腴饱满、面若银盆、肌肤胜雪（唐以胖为美）
- **发型**：峨髻 / 高髻 / 堕马髻，满头金翠步摇 / 花钿 / 翠翘
- **神态**：自信、雍容、眼角含媚，可以微微侧目（与宋的"松弛"不同，唐是"张扬"）
- **体型**：袒胸（胡风）、纱罗披帛、半透纱感（与现代透视装轮廓不同，唐是自然垂坠）

### 服饰：齐胸襦裙 + 大袖纱罗
- **齐胸襦裙**：高腰线至胸下，裙腰系于胸部以下
- **大袖纱罗衫**：袖口宽大飘逸（与宋的窄袖褙子截然不同）
- **披帛**：从肩绕臂垂下的长丝带（唐特有，宋没有）
- **纹样**：宝相花 / 团花 / 卷草纹（饱满对称）
- **面料**：纱罗 / 缂丝 / 大红锦（高饱和、轻透飘逸）

### 场景：满画面 + 华贵
- 不要宋的"留白"，唐是**填满画面**
- 室内：宫廷华堂 / 花团锦簇庭院 / 牡丹台
- 室外：骑马 / 打球 / 踏青
- 道具：金银器 / 丝竹乐器 / 团扇

### 光影：明亮饱满 + 高饱和色感
- 光线偏暖黄（比宋更亮更饱）
- 不强调"漫射"，唐的画面**清晰锐利**（不靠雾感，靠色彩对比）
- 但仍要 85mm + 胶片感（不是 AI 后期效果）

### 色彩：高饱和撞色（这是与宋最大的差异）
- **石榴红 / 绛紫 / 鹅黄 / 翠绿 / 蜜桃粉**——**撞色大胆**
- 不要宋的"低饱和"，唐的色彩对比强烈但**不荧光**
- 整体色调：暖红 + 金 + 宝蓝 + 翠绿
