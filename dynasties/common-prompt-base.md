# 古风美人 · 跨朝代通用 Prompt 骨架

> 本文档是 `dynasties/{tang|song|wei-jin}/SKILL.md` 的**共享骨架**。每个朝代只在「服饰 / 色彩 / 气质」上分支，**人物结构 / 场景结构 / 光影结构 / 质感结构**完全复用本骨架。
>
> 来源：调参经验（实测）+ 永泰公主墓壁画 + 顾恺之《女史箴图》+ 南宋黄昇墓实物 + 博物馆资源。
> 反馈 / 补充：开 Issue 或 PR 即可。

---

## 1. 通用骨架结构（4 段式）

所有朝代的 prompt 都按这 4 段组织：

```
[主体]  + [场景]  + [光影]  + [质感 + 输出规格]
```

每段有**必备 5 元素**，写 prompt 时按这个顺序往上叠，**不要打散顺序**（前 3 段决定"是什么"，第 4 段决定"像照片"）。

---

## 2. 主体（人物）· 跨朝代通用 5 元素

按顺序加，**不要堆形容词**，每个元素给 2-3 个挑一种写进 prompt：

| # | 元素 | 通用描述 | Tang / Song / Wei-Jin 差异 |
|---|------|---------|--------------------------|
| 1 | **身姿** | 斜倚 / 浅笑侧目 / 望向远方 / 抚琴 / 簪花 / 持卷 | Song 加重「松弛感」、Tang 加重「丰腴雍容」、Wei-Jin 加重「飘举出尘」 |
| 2 | **发型** | 低盘 / 高髻 / 灵蛇髻（朝代定）| Song=低盘+碎发；Tang=高髻+满头步摇；Wei-Jin=飞天髻+飘带 |
| 3 | **发饰** | 素簪 / 金翠步摇 / 飘带（朝代定）| Song=素色小簪；Tang=金翠满头；Wei-Jin=素纱飘带 |
| 4 | **服饰形制** | 褙子 / 襦裙 / 杂裾垂髾（朝代定）| Song=对襟薄纱褙子；Tang=齐胸襦裙+大袖纱罗；Wei-Jin=杂裾垂髾+宽袖 |
| 5 | **神情** | 浅笑 / 凝眸 / 微颔 / 蹙眉 | Song 加重"淡"；Tang"自信雍容"；Wei-Jin"超然物外" |

## 3. 场景 · 跨朝代通用 4 元素

| # | 元素 | 通用描述 | 三朝代差异 |
|---|------|---------|-----------|
| 1 | **空间** | 园林水榭 / 庭院一角 / 室内窗前 | Song=留白极简；Tang=丰满浓艳满画面；Wei-Jin=自然山水+留白 |
| 2 | **前景遮挡** | 一支荷叶 / 一片芭蕉 / 一枝垂柳 | Song=必加（遮 1/4 画面）；Tang=少遮挡（更"出镜"）；Wei-Jin=垂柳+衣袂 |
| 3 | **中景** | 木栏杆 / 廊柱 / 水面 | Song=廊亭斜倚；Tang=室内华堂；Wei-Jin=溪畔松下 |
| 4 | **远景** | 池水亭台 / 远山 / 月 | Song=朦胧水墨；Tang=金碧远景；Wei-Jin=云山墨色 |

---

## 4. 光影 · 跨朝代通用 3 元素

| # | 元素 | 通用描述 |
|---|------|---------|
| 1 | **光线方向** | 傍晚黄金侧逆光，从人物斜后方打过来 |
| 2 | **光效** | 发梢 / 衣边镶一层柔光金边 |
| 3 | **大气** | 薄雾漫射 → 弱化所有生硬阴影，皮肤透出自然通透感 |

---

## 5. 质感 · 跨朝代通用 4 元素（必带 = 直接砍"AI 塑料感"）

| # | 元素 | 通用描述 |
|---|------|---------|
| 1 | **镜头** | 85mm 浅景深 |
| 2 | **色调** | 暖杏 / 茶白 / 低饱和 —— 坚决避开高饱和亮色 |
| 3 | **材质** | 棉麻 / 纱罗 / 真实纤维（不要"丝绸光滑"那种 AI 词） |
| 4 | **颗粒** | 细微胶片颗粒，写真级出片 |

---

## 6. 反面清单（任何朝代都不能出现）

```
❌ 不要：浓妆 / 网红脸 / 亮片闪粉 / 高光滤镜 / 现代妆容 / 西式剪裁
❌ 不要：高饱和亮色 / 厚重大袖 / 华丽头饰堆砌
❌ 不要：紧绷束身 / 现代内衣轮廓 / 飘逸过头的塑料感
❌ 不要：AI 滤镜词（"8k", "trending on artstation", "unreal engine render"）
❌ 不要：脸崩 / 多手指 / 透视错误（任何 AI 通病）
```

---

## 7. 输出规格（放最后一段）

```
[历史时期] + [场景类型] + [人物姿态] + [光线] + [质感] + 85mm portrait, low saturation, film grain, soft haze, museum-quality composition
```

例（Song）：
```
Southern Song Dynasty lady, leaning on wooden rail by lotus pond in scholar's garden, low chignon with simple jade hairpin, sheer silk beizi over inner robe, soft golden rim light at dusk, soft atmospheric haze, 85mm portrait lens, low saturation palette of warm apricot and lotus-leaf green, subtle film grain, museum quality
```
